# Security policy

Ajour handles your SimpleLogin API key, so security reports matter. Please don't open a public issue for a vulnerability.

## Reporting a vulnerability

Report it privately through [GitHub's vulnerability reporting](https://github.com/JonasDoebertin/ajour/security/advisories/new). Include what you found, how to reproduce it, and which version of Ajour and macOS you used.

## Supported versions

Fixes go into the latest release. Please check that the problem still exists there before reporting it.
